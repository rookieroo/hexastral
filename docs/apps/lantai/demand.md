# 从需求反推：Lantai / Syel 各干什么

> 2026-08-19 · **形态 SSOT**（先于 [plan.md](./plan.md) 的实现细节）。
> 不从仓库能力往回编故事。Yuun / Yuel 不在本页展开。

乱的原因：把「拍三张脸/掌」「快捷指令」「Notion」「算命」「记账日活」叠进同一个 App，每轮只改一层。下面先写人已经在做的事，再映射产品。

---

## 1. 人已经在做的事（与 vibe coding 无关）

| # | 要办的事 | 现在怎么解决 | 多久一次 | 为什么付钱 |
|---|---|---|---|---|
| **J1 看今天** | 今日宜忌、日子顺不顺 | 纸黄历、Yuun、日历 | 每天扫一眼 | 工具免费层 + 个性化订阅 |
| **J2 问一句命** | 事业/感情/身体这段时间怎么走；想听像先生看过形和盘 | 找师傅、直播间、一次性 App 报告 | 几个月一次，或换运时 | **高客单**（一次座位） |
| **J3 记一笔** | 不想打字：餐、票据、inbox、习惯 | 备忘录、薄荷健康、相册堆着、小红书买的 Notion 指令 | 一天多次到每周 | **订阅**：省时间，并且能回头看 |
| **J4 有没有变** | 体重、饮食、气色、习惯是否在走 | 相册对比、Excel、什么都不记 | 看周/月 | 寄生在 J2 或 J3 的历史上，单独不成 App |
| **J5 接到我的笔记库** | 已经有 Notion 的人：指令写进自己的库 | 小红书 SKU、Nautomate、自己写快捷指令 | 配一次，用很久 | **买断** 或附赠；vibe coding 能自建，**不是大众市场** |

J1 = Yuun。J5 是真需求但很小，不能当公司定位。

vibe coding 能替代的是 **J5 的管道**（指令 + Notion + 模型）。替代不了的是：**不会配工具的人把 J3 做完，以及愿意为 J2 付一次座位钱。**

## 2. 由需求推出的两个产品（不要第三种）

### Syel ← J2（问命）

人要的是 **一次看相/看盘**，不是数据库。

- 同意 → 三张（脸、左掌、右掌）→ 生辰 → 付钱 → **一份形与命互证的报告**
- Pro：同一件事的时间轴 / 换运再拍（J4 落在「命」上）
- 不靠每天打开；不靠 Notion 才能成立
- 长文怎么展示（五章 vs 卡片）是阅读体验，不改变品类

### Lantai ← J3（记一笔）+ 很轻的 J4

人要的是 **快录进自己的库，并能在 App 里看见历史**。

- 打开 App 拍一张（或分享）→ 字段填上 → 列表/日历能翻
- 官方先做 **饮食**（日活最硬）；其余是用户自己的 schema（inbox、习惯、票据）
- 快捷指令 = 已经会用背面轻点的人的 **备选采集**，不是产品定义
- Notion = 已经住在 Notion 里的人的 **可选同步**（J5），不是首次必连
- 没有「算命结论」也能成立：观察的是 **用户自己记下来的字段**（热量区间、日期、标签）

### 刻意不重叠

| 不要 | 为什么 |
|---|---|
| 两个 App 都做「拍三张 → 一篇看相」 | 同一需求卖两次，审核和同意做两套，用户分不清 |
| Lantai 官方「精气神/气色看相」 | 这是 **J2**，不是 J3。日记里写气色 = 变相 Syel，文档才会一轮一轮改 |
| 用关美区/欧区来回避 J2 的同意 | J2 要么做（高水位同意），要么不做；地理开关解决不了欧日 |
| 把 Lantai 做成给 vibe coding 用的 MCP 底座 | J5 付一次就走；大众不在这儿 |

J4「气色有没有变」：要 **命理解释** → 去 Syel 再拍/Pro 时间轴。要 **自己留下的记录在不在** → 去 Lantai 翻饮食/自定义行。不要用「一段 AI 看相」同时满足两个。

## 3. 因此 Lantai v1 做什么、不做什么

**做：** App 内快录 + 观察（D1 存字段和短文，原图销毁）。饮食模板 + 自定义库。通知打开 App。可选 Notion、可选快捷指令。美/欧/日可卖饮食视觉（热量免责 + 餐图同意）。

**不做：** 官方脸/掌看相模板；五章；强制 Notion；Airtable；以快捷指令为唯一运行时。

**钱：** 订阅卖「拍照即填 + 能回头看」（J3）。买断卖槽位/多库。小红书指令是 J5 通道，不是主漏斗。

实现清单、定价、同意文案、iCloud 槽位仍见 [plan.md](./plan.md)。与本文冲突时 **以本文的分工为准**，改 plan，不要在 plan 里再叠一层相反的「锁定」。

---

## 4. 因此 Syel 做什么

**做：** J2 全套（同意、三图、生辰、报告、Pro 时间轴）。可选把 **已生成的报告** 同步到用户已连接的 Notion（复用连接，不是日常拍三张进日记）。

**不做：** 日常记账；和 Lantai 抢「打开就拍三张换短文」；用 Lantai 当获客主路径（可以互相链，不要合成一个漏斗）。
