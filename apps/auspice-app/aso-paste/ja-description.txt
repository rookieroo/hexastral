ユーン（Yuun）は、毎日の中華黄暦--宜忌、六曜、節気、旧暦、古典文化の参考をひとつにまとめたアプリです。

今日

- 今日ホーム：週ストリップ、干支・宜忌・六曜、任意の「あなたへ」
- 無料のホーム画面ウィジェット（小 / 中 / 大）、ロック画面、Apple Watch コンプリケーション--誰でも同じ公開黄暦
- 右スワイプで月カレンダー：太陽暦 + 旧暦 + 節気 + 祝日
- 左スワイプで設定：プロフィール、通知、ウィジェット外観、Apple カレンダー黄暦フィード
- 文化ライブラリ：二十四節気、中華の祝日、用語集（設定 / ライブラリ）

あなたへ（任意）

- 生年月日 1 件で毎日の「あなたへ」（Free は要約、Pro は理由の詳細）
- 生年月日を入れるとアプリとウィジェットに表示--Pro のロックではありません
- 四柱推命・紫微斗数の命式深掘り、人生タイムラインと「もしも」--Pro；予測ではなく内省

家族とリマインダー

- 家族の旧暦 / 太陽暦の誕生日を登録し、毎年正しい日に通知
- 朝のプッシュ + 任意の夜の予告
- Free：家族誕生日リマインダー最大 3 件 / Pro：無制限 + タイムライン節点

これは何ではないか

- 西洋占星術ではありません。占いでも、運命予測でもありません

Free vs Pro

Free：今日の宜忌・六曜 + 週ストリップ；月カレンダー；ホーム／ロック／Watch の公開黄暦；本人 1 名；あなたへ要約；毎日プッシュ；家族誕生日最大 3 件；Apple 黄暦フィード；文化ライブラリ

Pro ¥600/月 / ¥4,800/年：あなたへ理由の詳細 + 用神 / 吉色 / 吉時；四柱推命の人生グラフ & もしも；命式深掘り + Q&A；家族無制限 + 個人黄暦カレンダー；カスタム日付範囲；タイムライン節点リマインダー

3 つの使い方：匿名 Free（端末内の生年月日プレビュー、公開の朝プッシュ） /  サインイン Free（任意のアカウント同期、Watch credential） /  Pro（理由の詳細、タイムライン、命式深掘り）。AI 深掘りはタップ時のみ--プッシュには入れません。

動作環境 / iPhone iOS 15.1+ / ホーム／ロック画面ウィジェット iOS 17.0+ / Apple Watch watchOS 10+

言語：日本語 / 簡体中文 / 繁體中文 / English

プライバシー

生年月日は端末内プレビュー、またはマルチデバイス同期 ON 時にアカウントへ。通知 ON 時は Expo プッシュトークンとタイムゾーンを登録。購入は RevenueCat。設定からアカウント削除可。広告トラッキングなし。
