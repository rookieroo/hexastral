HOW TO PASTE INTO APP STORE CONNECT
=====================================

1. Open the locale file ending in -description.txt (NOT aso-metadata.json).
2. Open it in TextEdit (plain text).
3. You must see REAL blank lines between sections (TODAY, FOR YOU, PRIVACY...).
   If you see the two characters \n on screen, you copied from JSON — STOP.
4. Select All -> Copy -> paste into ASC Description -> Save.
