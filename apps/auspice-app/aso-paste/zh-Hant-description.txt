今日

- 今日首頁：週條、干支、宜忌，以及可選的「對你而言」
- 免費桌面元件（小 / 中 / 大）、鎖屏與 Apple Watch 複雜功能--人人相同的公開黃曆
- 右滑月曆：國曆 + 農曆 + 節氣 + 節日，可查任意年份
- 左滑設定：檔案、通知、元件外觀、Apple 日曆黃曆訂閱
- 文化庫：二十四節氣、傳統節日、百科（設定 / 文庫）

對你而言（可選）

- 錄入一條生辰：每日「對你而言」（Free 摘要；Pro 逐條原因）
- 生辰錄入後，App 與元件均可顯示--不因 Pro 鎖定
- 八字 / 紫微深讀、人生時間軸與「假如」探索--Pro；供省思，不作預測

家人與提醒

- 家人農曆 / 國曆生日，每年正確日期提醒
- 早間推播 + 可選晚間預告
- Free 最多 3 位親友生日提醒；Pro 無限 + 時間軸節點提醒

它不是什麼

- 不是西方占星或生肖運勢類應用
- 不作命運預測；僅供文化參考與個人省思

Free vs Pro

Free：今日宜忌與週條；月曆；主畫面 / 鎖屏 / Watch 公開黃曆；1 個本人檔案；對你而言摘要；每日推播；最多 3 位親友生日提醒；Apple 黃曆訂閱；文化庫

Pro $4.99/月 / $39.99/年：對你而言逐條解讀 + 用神 / 吉色 / 吉時；八字時間軸與假如；八字 / 紫微深讀與追問；無限親友提醒 + 個人黃曆訂閱；自訂擇日範圍；時間軸節點提醒

三種使用方式：匿名 Free（本機生辰預覽、公開早間推播） /  登入 Free（可選帳號同步、Watch 憑證） /  Pro（完整原因、時間軸、命書深讀）。AI 深讀僅在點開時生成，從不進入推播。
