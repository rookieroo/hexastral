# @zhop/widget-kit-ios

iOS WidgetKit infrastructure for HexAstral satellite apps.

## Usage (Yuun)

```jsonc
// app.json plugins
["@zhop/widget-kit-ios/plugin", {
  "widgetName": "AuspiceWidget",
  "appSlug": "yuun",
  "appGroupId": "group.com.hexastral.yuun",
  "watchComplication": true
}]
```

Xcode Widget / Watch targets for Yuun are generated by `@bacons/apple-targets`
from `apps/auspice-app/targets/{widget,watch}/`. This package owns:

- `YuunWidgetData` / envelope types
- `writeWidgetPayload` / `useWidgetSync` (via `RNSharedGroupPreferences`)
- App Group entitlement merge on the main app

See `docs/apps/yuun/widget-build-runbook.md`.
